# 🛡️ Phishing Detection Chrome Extension

A Chrome extension developed to identify potentially phishing websites using URL analysis and heuristic-based detection.

## Features
- Suspicious URL analysis
- Fake domain impersonation detection
- Risk score calculation
- Real-time phishing warning banner
- Login form detection
- HTTPS checks

## Technologies Used
- HTML
- CSS
- JavaScript
- Chrome Extension APIs

## Project Structure
- `manifest.json` – Extension configuration
- `background.js` – Background functionality
- `content.js` – Website analysis and phishing detection
- `popup.html` – Extension popup interface
- `popup.js` – Popup functionality
- `fake-login.html` – Phishing test page

## Installation
1. Clone or download this repository.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable Developer Mode.
4. Click **Load unpacked**.
5. Select the `phishing-detector` folder.

## Disclaimer
This project is intended for educational and cybersecurity learning purposes. Detection is heuristic-based and may not detect every phishing website.
